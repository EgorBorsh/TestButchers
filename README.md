# 🏃 Run Rich 3D Clone

## 📖 Описание проекта

Игра в жанре гипер-казуальный раннер с механикой сбора денег, смены статуса и прохождения через разные ворота в зависимости от накопленного богатства.

Игрок управляет персонажем, который автоматически бежит вперед. Задача — собирать деньги, избегать потерь и достигать финиша с нужным статусом для прохождения в соответствующие ворота.

---

## 🎮 Игровой процесс

### Основные механики

| Механика | Описание |
|----------|----------|
| **Автоматический бег** | Персонаж движется вперед по пути автоматически |
| **Управление свайпом** | Игрок управляет персонажем влево-вправо с помощью мыши или касания |
| **Сбор денег** | На уровне разбросаны монеты, которые увеличивают счет игрока |
| **Потеря денег** | Столкновение с препятствиями отнимает деньги |
| **Смена статуса** | В зависимости от количества денег меняется статус персонажа |
| **Смена скина** | При смене статуса меняется внешний вид персонажа |
| **Прохождение уровня** | В конце уровня нужно пройти в ворота, соответствующие текущему статусу |

### Статусы

| Статус | Денег | Описание |
|--------|-------|----------|
| Нищий | 0-40 | Начальный статус |
| Бедный | 40-250 | Первое улучшение |
| Состоятельный | 250-350 | Второе улучшение |
| Богатый | 350+ | Максимальный статус |

## 📝 Примечания

### Известные особенности

- Первый уровень полностью реализован
- Второй уровень является копией первого (шаблон для добавления новых уровней)
- Все пикапы и препятствия настраиваются в префабах уровней
- Анимации персонажа загружаются с Mixamo
